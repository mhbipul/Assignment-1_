## TypeScript Assignment 1

This repository contains my work for the Problem Solving with TypeScript & OOP assignment.

## Files

- [solutions.ts](./solutions.ts) - Solutions to eight TypeScript problems, covering types, functions, readonly tuples, generics, interfaces, classes, and Promises.
- [Type Aliases vs Interfaces](./type-vs-interface.md) - A blog post about when to use `type` and `interface`.
- [Understanding Type Narrowing](./type-narrowing.md) - A blog post with examples of `typeof`, `instanceof`, and `in`.

## About the Assignment

The assignment practices TypeScript concepts from Modules 1, 2, and 3. All eight coding solutions are in `solutions.ts`, and the two blog posts are separate Markdown files.
